# Road to Champions

Simulador de Valorant no navegador: monte um dream team com jogadores históricos do VCT, faça o veto de mapas
e tente vencer o Champions.

> Status: protótipo jogável (Draft clássico e Ultimate Draft → Champions com veto, série e tela final) com **cards reais**: 250 elencos de 18 eventos internacionais (2021–2026), stats do [VLR.gg](https://www.vlr.gg) e IGLs/técnicos da [Liquipedia](https://liquipedia.net/valorant/) (CC-BY-SA 3.0).

## Rodando

```bash
npm install
npm run dev     # http://localhost:5173
npm test
```
